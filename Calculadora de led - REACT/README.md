# 🎶Calculadora de Led

Este projeto visa a aplicação dos meus conhecimentos em **REACT**, servindo como prática para consolidar o aprendizado, também é utilizada como ferramenta pessoal de trabalho, facilitando calculos diarios que preciso fazer.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** → Estrutura base da página  
- **CSS3** → Estilização de componentes e responsividade  
- **JavaScript ES6** → Manipulação da DOM e interatividade
- **REACT** → Estrutura principal do projeto, componentização

---

## 📌 Observações

- **Compatibilidade**: O projeto possui suporte para dispositivos móveis, notebooks e computadores.   
- **Estética**: O projeto ainda vai passar por melhorias visuais, o foco por enquanto ainda é o desenvolvimento do codigo

---

## 📝 Sobre o Projeto

Este projeto é um laboratório pessoal, onde testo meus conhecimentos em React. À medida que adquiro novas habilidades e passo a conhecer a tecnologia de forma mais aprofundada, pretendo implementar mais funções para tornar a calculadora mais dinâmica e precisa.

Quanto ao uso do projeto no meu dia a dia de trabalho, na versão atual ele já facilita bastante, realizando cálculos e contagens que antes eu precisava fazer manualmente ou em planilhas. No entanto, ainda não atende 100% das minhas necessidades, pois algumas etapas continuam sendo feitas manualmente. Isso ocorre porque ainda não possuo conhecimento suficiente para implementar tudo o que é necessário para automatizar completamente o meu processo de trabalho.

---

## 🚀 Próximos Passos

- Adicionar contagem de barras e sobras, além de desenvolver um algoritmo que calcule de forma eficiente quantas barras serão necessárias para que não haja desperdício.
-  Adicionar uma validação para somas e multiplicações. Essa não é uma etapa fácil, pois preciso que toda a adição siga meu padrão de trabalho. Por exemplo: caso o usuário digite 1.55+5+7.55, cada um desses valores deve ser adicionado em uma linha diferente, com suas barras/perfil calculadas individualmente, enquanto as fontes devem ser calculadas de acordo com o resultado da soma. Isso traz uma enorme complexidade ao projeto, motivo pelo qual essa etapa ainda está em estudo.
  A mesma lógica se aplica à multiplicação. Exemplo: se o usuário digitar 3*5, preciso que sejam declaradas 3 linhas diferentes com o valor de 5,00 m. Cada linha deve ter suas barras/perfil calculadas individualmente e suas fontes calculadas a partir do resultado da multiplicação.
- Possibilitar que o usuário edite um valor já digitado, para evitar que, em caso de erros, todos os valores precisem ser inseridos novamente. Além disso, os cálculos devem ser refeitos de acordo com o novo valor informado.
