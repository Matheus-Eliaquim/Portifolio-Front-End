# 🎶Calculadora de IMC

Este é um exercico do Curso Hora de Codar, **REACT**, servindo como prática para consolidar o aprendizado.

## 🚀 Tecnologias Utilizadas

- **HTML5** → Estrutura base da página  
- **CSS3** → Estilização de componentes e responsividade  
- **JavaScript ES6** → Manipulação da DOM e interatividade
- **REACT** → Estrutura principal do projeto, componentização
